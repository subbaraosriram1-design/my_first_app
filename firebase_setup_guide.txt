FIREBASE CONNECTION GUIDE

1. FIREBASE CONSOLE SETUP
- Create a project at console.firebase.google.com.
- Add an Android app using your package name (com.example.my_first_app).
- Download 'google-services.json' and place it in the 'android/app/' directory.
- Add an iOS/macOS app. Download 'GoogleService-Info.plist' and place it in 'ios/Runner/'.

2. PROJECT CONFIGURATION
- Android: The project's build.gradle files are configured to include Google Services.
- iOS/macOS: You MUST run 'pod install' in the 'ios' or 'macos' directory after adding plugins.

3. FLUTTER CODE INITIALIZATION
- In main.dart, the connection is established in the main() function:

  void main() async {
    WidgetsFlutterBinding.ensureInitialized();
    await Firebase.initializeApp(); // This line connects the app to Firebase
    runApp(const MyApp());
  }

4. USING THE CONNECTION
- Once connected, you can use:
  - FirebaseAuth.instance (for Login/Sign-up)
  - FirebaseFirestore.instance (for Database storage)

5. TROUBLESHOOTING MACBOOK / VS CODE CONNECTION ISSUES

A. Missing CocoaPods (iOS/macOS)
If you see errors about "FirebaseCore" not found or "pod" command:
1. Open Terminal in VS Code.
2. Run: brew install cocoapods (if not installed)
3. Run: cd ios
4. Run: pod install
5. Restart your VS Code and run the app.

B. Network Permissions (macOS Desktop)
If running as a macOS app (not Simulator), network is blocked by default:
1. Open 'macos/Runner/DebugProfile.entitlements'.
2. Add: <key>com.apple.security.network.client</key><true/>
3. Repeat for 'Release.entitlements'.

C. Firewall/VPN
Ensure no firewall or VPN is blocking access to *.googleapis.com or *.firebaseio.com.

D. Verification Command
Run 'flutter doctor' to ensure all tools are correctly set up on your MacBook.
